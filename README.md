# bae6-ai

AI inference and metering gateway for AWS Bedrock and GCP Vertex AI, with optional agents,
evals and guardrails packages. `core` never depends on the optional packages.

Plan: [bae6-contracts/docs/plans/02-AI.md](https://github.com/basics-only/bae6-contracts/blob/main/docs/plans/02-AI.md).
